## Garde-fous de campagne

- Une seule personne/session est opérateur ADB à un instant donné. En phase 0, seul ENV peut utiliser ADB et uniquement en lecture stricte ; le parent n'utilise pas ADB.
- Les tests réels distinguent Pixel, AVD, service local, réseau public, Bridge réel et mock. Aucun résultat ne se transfère d'un environnement ou d'un SHA à un autre.
- Les secrets restent hors Git et hors traces. Les fixtures et rapports n'utilisent pas de données personnelles.
- Toute modification de service, de configuration OpenClaw active, tout redémarrage Gateway, action sensible Pixel ou changement distant requiert l'autorisation ciblée correspondante avant exécution.
