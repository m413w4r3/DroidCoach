Fail-closed/idempotency contract:

- ATLAS_ALLOW_LOOPBACK_WS must equal "1" to opt into local ws:// through
  configFromEnvironment(); default is deny. Tests pass the option explicitly.
- Effectful plan.revision.request POSTs are journaled atomically in the private
  state directory before backend dispatch. A recovered in-flight entry becomes
  uncertain and is never replayed blindly.
- Same-key retries during the 10-minute cache window return
  BACKEND_UNAVAILABLE, retryable=false, with the deterministic message:
  "backend outcome is uncertain; retry is blocked until the 10-minute
  idempotency window expires". Different content returns IDEMPOTENCY_CONFLICT.
- Safe GET/read operations remain retryable. Completed POST outcomes are
  journaled and replayed without another backend call.
- ENOENT for devices.json may start an empty registry; invalid JSON and ordinary
  read errors fail startup/authentication closed.
