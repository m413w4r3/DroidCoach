Invariant
---------
`pair-device` creates the one-time token file exclusively with mode 0600,
syncs and closes it, then commits the authorized device under the existing
cross-process registry lock. A failed token-file write cannot authorize a
device. A failed registry commit compensates by removing the token file when
it is still the file created by that attempt. A crash before registry commit
may leave an orphan token file; it cannot leave an authorized device with an
undelivered token. The registry writer does not perform fallible work after
the atomic rename that commits the new document. An unreadable or invalid
registry fails closed and is never replaced with an empty document.

The CLI reports device ID, label, capabilities, and token-file path only. The
token is present once in the 0600 JSON token file and is not printed to stdout
or stderr.
