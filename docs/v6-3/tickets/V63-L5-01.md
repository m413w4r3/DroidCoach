## Objectif observable

Livrer un module backend d'intégration wger **lecture seule** avec deux
adaptateurs d'authentification sous une interface unique, une pagination
validée, une gestion explicite des erreurs, un stockage JWT rotatif atomique, et
un diagnostic expurgé. **Aucun appel réseau réel dans les tests ; aucune écriture
wger ; le refresh token n'est jamais consommé automatiquement.**

## Interfaces

```text
WgerAuth (Protocol) -> headers() -> dict[str,str]
ApiTokenWgerAuth(token)                  # Authorization: Token <...>
RotatingJwtWgerAuth(store, http, now)    # Authorization: Bearer <access>
WgerTokenStore(path)                     # 0600, écriture atomique, verrou
WgerClient(base_url, auth, http, limits)
  .probe() -> WgerProbe
  .list_routines() -> list[RoutineSummary]
  .list_exercises() -> list[ExerciseSummary]
  .list_workout_logs() -> list[WorkoutLogSummary]
```

- `WGER_AUTH_MODE=api_token|jwt_refresh` ; si absent et `WGER_API_TOKEN`
  présent → `api_token` ; sinon `CONFIG_REQUIRED`.
- `WGER_REFRESH_TOKEN` n'est **jamais** lu automatiquement pour passer en JWT.
- `RotatingJwtWgerAuth` est **implémenté et testé avec faux serveur**, mais
  **inactif** : aucun endpoint ni script ne l'active dans cette campagne.
- Pas de fallback silencieux JWT → API token.

## Stockage JWT

- Fichier séparé, ignoré par Git, sous `backend/data/` (ou chemin configuré).
- Mode `0600` sur POSIX ; écriture `tempfile` + `fsync` + `os.replace`.
- Verrou fichier/processus empêchant deux rotations concurrentes.
- Champs : génération, access token, refresh token, obtenu le, expire le, état
  `ACTIVE|RECONCILIATION_REQUIRED`.
- Après un renouvellement dont la persistance est incertaine :
  `RECONCILIATION_REQUIRED` et **aucun retry aveugle** avec l'ancien token.
- Aucun token dans les logs, exceptions, `repr`, preuves ou fixtures.

## Erreurs

`AUTH_INVALID(401)`, `FORBIDDEN(403)`, `RATE_LIMITED(429 + Retry-After)`,
`SERVER_ERROR(5xx)`, `TIMEOUT`, `SCHEMA_ERROR`, `UNAVAILABLE`. Chaque erreur
porte un code stable et un message expurgé.
