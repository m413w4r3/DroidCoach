## Objectif observable

Depuis l'écran Plan du jour, un bouton « Demander au coach » permet, après une
divulgation explicite, d'envoyer le plan courant au backend local, de recevoir
une proposition `plan.revise_day`, d'afficher son diff et de la confirmer via le
dialogue groupé existant. Rien n'est appliqué sans confirmation.

## Contenu

1. `AtlasController.kt` :
   - constante `CAP_PLAN_REVISION = "planRevision"` ;
   - défaut `false` dans `readCapabilities` ;
   - accès en lecture au `syncBaseUrl` et au token provider existants ;
   - aucune requête automatique.
2. `PlanScreen.kt` :
   - section « Coach » visible seulement si `capabilities[CAP_PLAN_REVISION] == true`
     et backend configuré ;
   - bouton « Demander au coach » → dialogue de divulgation : « Le plan du jour
     (titre, horaires, durées, priorités, objectif) sera envoyé au coach local
     OpenClaw. Aucun calendrier ni identifiant n'est envoyé. » ;
   - champ message optionnel, borné ;
   - action « Envoyer » → coroutine IO, `PlanRevisionApiClient`, états :
     chargement, `proposal=null`, `agent_status` non ok, erreur réseau, succès ;
   - succès → `controller.proposeAgentRevision(proposal)` ; le dialogue de
     prévisualisation existant affiche le diff et la confirmation groupée ;
   - bouton « Désactiver les révisions par le coach » qui remet la capability à
     `false` et efface tout état de proposition en attente.
3. `AtlasScreens.kt` / `AtlasApp.kt` :
   - fournir le client au `PlanScreen` (URL/token existants) ;
   - aucune nouvelle permission, aucun nouveau réseau hors backend configuré.
4. Tests JVM/Compose si le harnais le permet : visibilité conditionnelle,
   consentement obligatoire, capability off, erreur client, proposition nulle,
   succès → preview, désactivation.

## Invariants

- Aucun envoi automatique : seulement après action et consentement explicites.
- Le plan envoyé est minimisé (pas de notes libres, pas de données calendrier).
- Aucun token, message ou plan dans les logs.
- `planRevision` reste désactivable indépendamment.
- Aucune écriture calendrier dans ce ticket.
